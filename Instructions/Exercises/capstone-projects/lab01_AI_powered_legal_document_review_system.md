# AI-Powered Legal Document Review System

## Project Statement

Create a multi-agent AI system that reviews legal documents, flags compliance issues, and provides grounded summaries using RAG and Agent Framework

## Pre-Requisites

Azure subscription, Azure AI Agent Service, Azure AI Foundry /Copilot Studio, Azure AI Search, Blob Storage, Microsoft Agent Framework

## Requirements

- Design agents for document ingestion, clause extraction, and compliance validation

* Use RAG to retrieve legal precedents and summarize findings

- Implement orchestration for dynamic task planning and memory retention

* Orchestrate agents via Azure AI Foundry/Copilot Studio

## Deliverables

- Public Google Drive folder with agent workflows and RAG implementation

* PPT with architecture, workflows

- Screenshots of working assistant
